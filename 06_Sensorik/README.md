
# Sensorik und Datenerfassung

Dieser Ordner enthält die Dokumentation der Sensorsysteme.

## Hardware
- Holybro GPS M10
- DroneCAN RM3100 Kompass

## Aufgaben
- Integration der Sensoren
- Konfiguration der Schnittstellen
- Erfassung und Auswertung der Messdaten
- Kalibrierung des Kompasses
- Dokumentation der Messergebnisse
- Entwicklungsprotokolle
