# MUSV – Mechatronikprojekt 2026/27

**Ernst-Abbe-Hochschule Jena (EAH Jena)**

Entwicklung und Erprobung eines ferngesteuerten Modell-Wasserfahrzeugs (Unmanned Surface Vehicle, USV).

## 1. Projektbeschreibung

Ziel dieses Projekts ist die Konstruktion, Fertigung und Erprobung eines verkleinerten Wasserfahrzeugs auf Grundlage eines bestehenden USV-Projekts.

Das Wasserfahrzeug soll mithilfe einer Fernsteuerung gesteuert werden. Zwei unabhängig angesteuerte Propeller ermöglichen die Fortbewegung und Richtungssteuerung.

Zusätzlich werden ein GPS-Modul und ein elektronischer Kompass integriert, um Sensordaten zu erfassen und auszuwerten.

Eine autonome Navigation ist nach dem aktuellen Projektstand nicht vorgesehen.

## 2. Projektziele

- Mechanische Konstruktion mit Autodesk Inventor
- Fertigung von Bauteilen mittels 3D-Druck
- Integration des Antriebs- und Energieversorgungssystems
- Implementierung der Fernsteuerung mit ArduPilot Rover
- Integration von GPS und Kompass
- Durchführung und Dokumentation von Systemtests
